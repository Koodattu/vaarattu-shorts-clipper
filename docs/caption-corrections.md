# Caption word corrections

New runs have an optional **Automatically correct clear caption word errors before rendering** setting, off by default. It runs on final selected clips after optional large-v3 transcription. It uses the run's existing provider, cut-review reasoning setting and spending limit. Local models load once for the correction batch and exit before rendering. Completed corrections are saved so a resumed render does not repeat the pass. Manually edited clips are excluded from automatic passes.

**Check caption errors** in the review queue and editor opens the same suggestion panel. A check uses the durable worker and keeps the existing preview and review decision. Closing the panel leaves captions unchanged and does not cancel a queued check. Reopen it to see results. Select individual replacements and choose **Apply selected and render** to create a new revision. The previous preview remains available. **Undo last corrections and render** restores the last applied words unless subsequent edits conflict. Unsaved editor changes must be saved before checking the saved clip.

The model receives caption word IDs/text and up to 20 seconds of surrounding speech, reducing context if needed. It receives no generated title, editorial justification, timestamps or audio. It must return only word replacements with exact originals and short reasons, or an empty list. The prompt preserves dialect, slang, code-switching, repetitions and deliberate unusual language; it requests no example-specific substitutions.

Validation rejects unknown/duplicate IDs, mismatched originals, protected manual words, empty or multiword replacements, excessive length, and excessive changes (at most 12 words and 20% rounded up). Timing, order, clip boundaries and untouched words remain unchanged. Splitting, merging, missing speech and timing errors need manual/audio review. These structural checks cannot prove that a plausible replacement was spoken.

Original words and applied replacements are stored in `caption_corrections`; pending/completed suggestions in `caption_check`. Application verifies the saved revision, check ID and caption fingerprint. Editor changes protect the modified words. A failed model-output validation during an automatic pass retains original captions and records a visible warning; provider/access/budget failures retain normal explicit retry behavior. The original ASR transcript is never overwritten. New render revisions return to human review.
